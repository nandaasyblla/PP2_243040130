## Deskripsi

Aplikasi formulir pendaftaran kegiatan berbasis
Java Swing yang menggunakan komponen GUI,
Layout Manager, Event Listener, dan validasi input.

## Teknologi

- Java JDK
- Java Swing
- Visual Studio Code

## Cara Menjalankan

1. Pastikan JDK sudah terinstal.
2. Buka folder project di VS Code.
3. Buka terminal.
4. Jalankan perintah:

javac -d out src/p08/Main.java

5. Jalankan aplikasi:

java -cp out p08.Main
